# Constants Converter

This is a converter for converting constants from Pedro Pathing 1.0.9 and
earlier to 2.0.0. Try out the
[constants converter](https://pedro-pathing.github.io/ConstantsConverter) now!

## Running Locally

To run locally for development, run the following commands:

```bash
git clone https://github.com/Pedro-Pathing/ConstantsConverter.git
cd ConstantsConverter
npm install
npm run dev
```
